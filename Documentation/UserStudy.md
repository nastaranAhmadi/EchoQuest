# User Study

Usability evaluation protocol for the EchoQuest Bachelor thesis.

**Do not fabricate results.** Fill this document after real sessions.

## Research goal

Evaluate whether EchoQuest’s audio-based interaction allows blind and low-vision participants to navigate a small 2D environment and complete simple game tasks independently on Android.

## Research questions (examples)

1. Can participants complete Level 1 (locate via audio) without visual assistance?
2. Can participants identify the correct object in Level 2 using audio + narration?
3. Can participants complete the Level 3 sequence with acceptable effort?
4. How do participants rate clarity of audio cues and controls?

## Participants

- Target: blind and/or low-vision players familiar with smartphones
- Sample size for Bachelor scope: small (e.g. 3–8); report limitations honestly
- Inclusion: Android phone users (or provided test device), able to use headphones
- Exclusion: participants who cannot use audio output for safety/comfort reasons

## Tasks

| Task | Description | Success criteria |
|------|-------------|------------------|
| T1 | Start the game from the device home screen | Reaches main menu / hears menu |
| T2 | Complete or dismiss tutorial | Understands move + interact |
| T3 | Level 1 — find the target object | Interact with correct object |
| T4 | Level 2 — identify correct object | Interact with narrated target |
| T5 | Level 3 — complete sequence puzzle | Correct order completed |
| T6 | Change one accessibility/audio setting | Setting change confirmed in play |

Allow a fixed hint policy (e.g. after 2 minutes or on request). Record hint count.

## Metrics

| Metric | How collected |
|--------|----------------|
| Task completion (yes/no) | Observer checklist |
| Completion time | Stopwatch / log timestamps |
| Errors (wrong interacts, menu mistakes) | Count |
| Hints requested / given | Count |
| Perceived difficulty | 1–5 scale item |
| Qualitative feedback | Short interview |

## Questionnaire (neutral wording)

Use a 1–5 scale (1 = strongly disagree, 5 = strongly agree) unless noted.

1. I could understand what the game wanted me to do.
2. I could move through the environment with confidence.
3. Sound cues helped me find objects.
4. Narration was clear and useful.
5. Touch controls were easy to use.
6. Menu navigation was understandable.
7. The tasks were appropriately difficult.
8. I would describe the experience as enjoyable.
9. What was most helpful? (open)
10. What was most difficult or confusing? (open)
11. Any suggestions? (open)

## Session procedure

1. Consent and demographics (non-identifying as required).
2. Device + headphone setup.
3. Brief orientation (no spoilers of puzzle answers).
4. Run tasks T1–T6.
5. Questionnaire + short interview.
6. Thank participant; store data per ethics plan.
